# 生图执行适配

## 目的

本 skill 只规定版式、视觉系统、精确文案、参考资产和验收标准，不绑定任何模型、供应商、中转站、接口地址或 API key。安装者可以使用当前环境的内置 `imagegen` 能力、自己的 API 客户端、企业内部生图服务或其他已获授权的生成方式。

## 执行原则

- 先按本 skill 生成结构化提示词与输入图清单，再交给当前使用者可用的生图工具执行。
- 模型与服务商由当前使用者决定。不要因为历史生成记录使用过某个模型或接口，就将其当成后续必选配置。
- 认证信息只能来自当前使用者的环境变量、密钥管理器、应用设置或其明确提供的临时运行配置；不得写入 skill、参考文档、提示词文件、生成记录、Git 仓库或输出图片。
- 如果当前环境支持图像输入，将本轮主视觉、固定品牌标题 PNG 和用户明确提供的其他素材按角色标注为参考图；固定品牌标题必须原样放置，不得由模型重新输入同一句英文。
- 如果当前环境不支持多图输入，先保留固定标题资产、主视觉和版式模板的角色说明，再使用该工具支持的等价方式完成；不得 silently 换成无参考的通用海报。
- 模型、尺寸、质量、输出格式和并发方式由当前工具的能力与用户需求决定；必须满足本 skill 的尺寸、文字、版式和验收要求。

## 推荐调用上下文

每次执行前准备以下信息：

1. `Primary request`：本轮物料类型、尺寸、精确文案和层级；
2. `Input images`：主视觉、固定标题资产、用户提供的照片/插画和必要参考图，并标明每张图的角色；
3. `Composition`：按 `version-1-panel` 选择白色信息平面的数量、大小、错位、留白和内部模块；
4. `Color`：从本轮主视觉读取主色与最多 1–2 个辅助色，不复用其他站次的固定色值；
5. `Constraints`：文字逐字准确、水平直立、无可见网格、无无关 logo/装饰，白色平面只承担明确内容或视觉重心。

首张只作为预览，用户确认后再批量生成。无论使用何种模型或接口，输出都必须按主 skill 的逐张核验规则检查。
