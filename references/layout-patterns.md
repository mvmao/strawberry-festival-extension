# 已验证版式结构（已由 version-1-panel 固化为最终模板语法）

当前默认基准不是旧的 `grid-v3/grid-v4` 结构，而是同目录 `approved-panel-template.md` 与 `assets/approved-templates/version-1-panel/`。以下旧结构只保留为内容分类参考；它们的纯红无面板路线不再是默认路线。

以下结构来自工作区此前的 `grid-v3`/`grid-v4` 生成记录。它们只保存版式关系和信息层级；每次新尺寸仍需重新计算，不得直接缩放。

## 票价信息

- 3:4 竖版可用约 6% 外边距、五栏、约 2% 栏距和六个水平节奏区。
- 默认优先将票价信息放入一个或多个不规则白色信息平面；四个价格可在同一大平面中错位，也可拆成两个大小不同的平面。白色平面使用黑色描边，本轮主视觉色背景保留为负空间。
- 顶部左侧放紧凑三行品牌锁定；四个价格分别落在上左、上右、下左、下右的不同栏位，最大价格获得最大字号，但四个价格共享稳定基线/边缘关系。
- 票种紧随价格，购票限制与平台列表降为三级，日期降为四级；价格场和底部说明之间保留一块安静的主视觉色空区。
- 不绘制普通矩形卡片或可见网格；模板白色平面内部允许有限的细分隔线作为信息层级锚点，但不能将每组信息机械包装成独立卡片。

## 权益信息

- 3:4 竖版可用六栏、约 6% 外边距、约 2% 栏距和七个水平节奏区。
- 按第七张模板的逻辑，权益行可以共享一个大白色平面，也可以拆成两个错位平面；平面之间保留本轮主视觉色呼吸区。
- 上半部左右比较两种价格：预售和全价共享一条水平基线但字号可不同；“优享单日票”跨中栏作为二级标签。
- 五条权益沿同一图标/文字边排列，按文案长度改变行高，不用行框或分隔线；下半部右侧保留大块纯红空区。
- 功能图标只用简单线性符号，且必须与文字列边对齐；图标不是装饰插画。

## 实名购票信息

- 3:4 竖版可用四栏、约 6% 外边距、约 2% 栏距和七个水平节奏区。
- “实名购票”跨第一至第三栏作为一级标题，“别买错”错位跨第二至第四栏作为第二个大字块；两者均保持水平直立。
- 三条关键规则在中部沿隐形基线排列，辅助说明沿同一侧边收束；身份证、日历、票券和监护人符号只能作为低调功能标记。
- 右下或下方保留开放的主视觉色区域。禁止用固定色值制作警示框、边框、封闭信息卡或机械表格。

## 共同复用规则

三种版式共用阿里巴巴普惠体式粗正体、主视觉色/白/黑克制色板、严格水平基线和大面积负空间；默认使用不规则白色信息平面承载内容。下一张物料至少更换一个平面数量、主标题锚点、模块顺序、空区位置或栏位合并方式，保持系列感而不是复制版式。
